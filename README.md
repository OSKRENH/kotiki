# Помоги нам найти дом — Эталон × Vetcity Adoption

Лендинг проекта по спасению бездомных кошек с территории «Электрозавода».
Полностью переработанная версия страницы `etalonhelp.tilda.ws/cathelp`:
сохранены фирменная цветовая гамма, логотипы, фотографии, карта и весь текст
оригинала, но добавлены современная вёрстка, анимации и сквозные CTA.

## Структура

```
index.html            — разметка страницы
assets/css/style.css  — дизайн-система, компоненты, анимации, адаптив
assets/js/main.js     — скролл-анимации, счётчики, лайтбокс, ленивая карта
assets/js/lqip.js     — автогенерированные размытые превью фотографий
assets/js/cats.js     — данные пяти подопечных (имя, возраст, характер, тексты, галереи)
assets/img/           — логотипы, фотографии, иконки, QR-код
assets/img/cats/      — фотогалереи подопечных
```

## Что происходит на странице

* **Первый экран** — Ken Burns + параллакс фото, пословное раскрытие заголовка,
  счётчики, плавающие лапки, индикатор прокрутки.
* **Бегущая строка** — зацикленная марки-лента с ключевыми сообщениями.
* **История** — двухколоночный блок с реверсивным появлением и «маркерной»
  подсветкой ключевых слов.
* **Подопечные** — пять карточек (Лена, Сима, Нева, Волга, Енисей); по клику
  открывается анкета с фотогалереей, характеристиками, полным текстом
  и ссылкой на анкету усыновления. Управление стрелками и Esc.
* **Хроника спасения** — документальные кадры отлова и приёма у врача
  с лайтбоксом.
* **Цитата** — слова проявляются каскадом при попадании в кадр.
* **Как мы помогаем** — три шага с растущей соединительной линией и иконками
  из оригинала.
* **Пожертвование** — оранжевый блок с QR-кодом СБП и «сканирующей» анимацией.
* **Контакты** — карта Яндекса подгружается лениво, ч/б до наведения.

## Производительность и доступность

* Фотографии пережаты (первый экран: 1.9 МБ → 143 КБ), для каждой встроено
  base64-превью 24 px — плавная загрузка без «прыжков».
* Карта монтируется через `IntersectionObserver` только при подходе к блоку.
* `prefers-reduced-motion` отключает все анимации.
* Семантические заголовки, `alt`-тексты, skip-link, видимый фокус,
  управление лайтбоксом с клавиатуры.

## Запуск

Статика без сборки — достаточно любого сервера:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Источник материалов

Фотографии, логотипы, иконки, QR-код и тексты взяты с
[etalonhelp.tilda.ws/cathelp](https://etalonhelp.tilda.ws/cathelp).
Карточки подопечных — из ленты «Catsaver» того же проекта (Tilda CMS,
`feeduid=166910607191`); данные зафиксированы в `assets/js/cats.js`,
поэтому правки в ленте не подтягиваются автоматически.
